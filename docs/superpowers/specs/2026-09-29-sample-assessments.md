# Sample assessments design

Show three illustrative audio-quality assessments on Home and Records when the current guest or authenticated account has no saved assessments. Use existing report cards and ResultsScreen, with visible Sample labels and an explanation that values are illustrative. Cover acceptable, needs-improvement, and problematic outcomes; show the existing five measured features and noise/distortion estimates. Do not claim a recording was analyzed or fabricate downloadable visualization files.

Samples are presentation-only: never save, upload, import, or consume guest allowance. A successfully loaded nonempty history replaces all samples. Do not use samples for failed loads or filtered-to-empty histories. Guests use local guest history; accounts use their own authenticated API history. Returning from a real assessment or entering Records refreshes the displayed history.

Sample details reuse the real results UI but omit completion claims and unavailable visual-report actions. Back returns to the originating list. Add a Sign in action beside Create Account in the guest Home banner, with wrapping at narrow widths. Permanent light theme remains.

User authorized autonomous design, planning, and implementation. Execute inline on the existing feature branch; preserve earlier branding changes.
